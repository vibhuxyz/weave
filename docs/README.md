# Docs

[PRODUCT](PRODUCT.md) is how Weave works now: personas, employees, skills, plugins, engines, and avatars. If another document disagrees with it, PRODUCT.md wins. When the code changes, update PRODUCT.md in the same change.

Tier and phase documents are history. They record what each version was meant to add. They are not a second product spec. A path in those files that says `.berd/`, `@berd/*`, or `packages/cli` is the name from that plan. This tree uses `.weave/` and has no `packages/cli`.
